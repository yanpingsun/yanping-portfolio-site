# general 本轮改造方案：内容与 UI/UX 分开推进

日期：2026-11-02。依据本轮试读反馈与[内容／体验复核](../design/reviews/general-html-r1-content-ux-review.md)。展示版本仍为general；内容r3、UX r2、HTML r1及原版继续作为比较基线。本轮先交付提案与静态设计，不自动改写现有网页。

## 目标与取舍

这是求职用的个人作品集。快速浏览应能识别定位、核心判断、代表作品和个人贡献；认真阅读应能理解背景、取舍与执行，并能继续查阅完整证据。内容质量是第一目标，视觉和交互帮助这些内容被看见。

- 收短重复说明，保留独特的作品与思考，不以固定字数或压缩比例判断质量。
- 要点突出，必要解释保持正常可读的正文；日期、来源等辅助信息才使用次要样式。个人职责、团队成果范围和后期重建身份仍清楚可见。
- 通过真实文案、作品选择、内容线稿与成品、具体参与路径表现表达、审美与用户理解。网页包装不额外认定候选人具有未经证实的视觉设计或技术职责。
- 大作品、清楚的字体层级和适当留白形成展示感；控制导航及控件数量，避免每段卡片化或同时增加多套菜单。
- 原版有价值的大图和短主张保留为设计起点；现版对分工、材料身份和数字范围的准确说明继续保留。

## 分开交付、分开调整、分开 review

| 工作 | 输入与本轮产物 | 自己负责的评审问题 | 不代替什么 |
| --- | --- | --- | --- |
| 内容 | 原材料、现有CV、原版正文、内容r3、通用定位；[内容方案及八份完整提案](../content/proposals/general-r4/README.md) | 单独读文稿能否讲清问题、判断、工作和结果；是否有重复或证据缺口；分工及数据是否准确 | 不以漂亮排版弥补空泛文案，不靠全部藏进补充材料制造精简 |
| UI/UX | 本轮已检查的文稿作为固定输入，现网页／原版及参考案例；[独立设计方案](../design/proposals/general-ux-r3/README.md)和桌面／手机静态稿 | 是否突出作品与要点，细读是否清楚，页面是否有适合该岗位的审美与展示判断，导航是否方便 | 不为适应版面偷偷删改正文，不把静态图当成功能已实现 |
| 最后核对 | 两条线各自调整后的版本 | 作品和解释是否相邻；关键限定是否被弱化；默认阅读和完整查阅是否都成立 | 不将两条线的自审合并成一句“整体通过” |

分别维护[内容review](../content/reviews/general-r4-review.md)、[UI视觉review](../design/reviews/general-ui-r3-review.md)与[UX阅读／交互review](../design/reviews/general-ux-r3-review.md)，写明发现、调整及仍需确认之处。它们是本轮agent的分项自审，不冒充独立招聘读者或外部设计师评审。

内容先形成不依赖版式也成立的提案，检查后供设计使用。设计可以独立研究版式与交互，但发现需要改文案时，把问题交回内容记录，更新输入后重新核对；不在设计图中私自改成另一份稿。无须为这次分工另设复杂人员角色。

## 整批范围

| 页面 | 内容本轮方向 | UI/UX本轮方向 |
| --- | --- | --- |
| 首页 | 简短主张、真实方向、两份代表项目及三个互补入口；旧版主张保留为候选 | 作品尽早出现，标题与封面有分量，主次清楚且不依赖悬停 |
| 精华油 | 一句共同表达、日夜差异、长文与不同口播；合并重复的结构说明 | 大图开篇、原作文案重点、线稿／成品对照、精选视频与清楚的完整作品入口 |
| 酷狗 | 发糖机的入口／规则／资源协作；音效与栏目补足持续运营 | 实际参与路径和作品并读，区分活动、平台内容和持续栏目，不做平台履历墙 |
| 防晒 | 价格与肤感两类顾虑，突出历史问答及不同视频处理 | 问题／回应与真实作品相邻，避免仿造真实客户聊天界面 |
| 面膜 | 升级沟通、人物故事转场及直播讲解 | 作品与关键片段优先，准确标明直播文字记录、成片分析等身份 |
| 洁面 | 短文案取舍，三组结构及长文仍可查 | 保持集中，避免把补充案例强拉成与主案相同长度 |
| 关于我 | 收拢与首页／案例重复的介绍，保留履历、工作方式和联系 | 履历清楚，文字层级稳定，简历与案例入口易找 |
| 作品目录 | 复用各案例的简短问题及工作范围 | 五案紧凑可辨，不新增筛选和搜索 |

## 执行顺序与当前状态

1. 整理方案：本文与两份分项方案，覆盖整批范围。
2. 首轮试点：精华油和酷狗分别代表产品内容与运营活动，先做完整内容提案及分项review；UI/UX先做精华油桌面／手机和导航状态静态稿，再用酷狗结构检查通用性。
3. 根据分项记录调整试点，再对照原版、现预览与提案看同一批证据。现有七稿继续是网页输入，不自动接入提案目录。
4. 在两案基础上扩展首页、关于、防晒、面膜、洁面与目录，并分别review；本批八份内容与八页桌面／手机静态稿现已完成。静态自审不代替本人或招聘读者试读。
5. 最后才实现新的HTML预览并检查真实交互；正式入口切换继续遵守既有预览与发布约定。
