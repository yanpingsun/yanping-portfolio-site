## 后续如何更新

重要决定记录 ID、日期、问题、最终选择、依据和影响；建议标为“建议”，明确采用后更新状态。替代旧决定时保留原 ID 并指向新决定，避免静默改写。

当前用户在具体任务中的明确要求可以调整一般规范；同步记录长期影响即可，不为日常文案修正、技术实现或小修增加审批步骤。
