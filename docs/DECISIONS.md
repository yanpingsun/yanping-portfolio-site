# 项目决定

更新日期：2026-11-01。

| ID | 当前决定 |
| --- | --- |
| GOV-001 | README 面向人，AGENTS 作为开发入口 |
| GOV-002 | 正常同步最新版本、在任务分支修改、通过 PR 整合 |
| GOV-003 | 区分事实、建议和当前实现，内容以确认材料为准 |
| GOV-004 | 首轮沿用静态 HTML/CSS/JS 与 GitHub Pages |
| GOV-005 | 先梳理内容，再做首页与主案例，然后扩展全站 |
| GOV-006 | owner 说明需求，agent 完成文件和 GitHub 操作 |
| GOV-007 | 资料共享、网页接入、合并和发布分别如实报告 |
| GOV-008 | 按用户最新要求保持轻量协作，取消强制接手回执与独立开工检查文件；具体流程以当前 AGENTS 和 COLLABORATION 为准 |
| GOV-009 | 按用户最新要求细化 GOV-005：原始材料 → 网页内容准备 → UI/UX → HTML 实现；当前先确定流程，再准备第二层内容，内容结构草稿与视觉设计稿分开 |

旧版细则由上述轻量流程替代。当前目标岗位、案例取舍与新设计随实际改版细化，不因已写在旧页面就永久固定。普通技术修改无需逐项新增决定。
