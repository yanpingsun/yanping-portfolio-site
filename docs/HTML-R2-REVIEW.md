# HTML r2：内容、UI、UX分别核对

日期：2026-11-03。输入是内容r4的八份完整提案、UI视觉方案和UX阅读／交互方案；前序内容、UI、UX分项自审分别保留，本记录不替代它们，也不是候选人确认或招聘读者测试。

## 内容接入

- 新生成入口使用 `--refined`，直接读取八份r4提案，保留来源校验值。原七份r3稿与旧HTML r1的数据未改变。
- 八份输入共343个公开正文块。实际浏览器将页面文字、补充展开内的文字及作品入口与输入逐项对照；标题的视觉拆行和历史主张的独立排版不另写文案。桌面及390px框架未发现正文或资源入口遗漏；320px框架正文也无遗漏。
- 5案的107个去重资源目标沿用前序提案，14组海报与11条成片都能查到。输入资源文件存在；目录封面指向案例，详细图像与原文件从案例查阅。
- 历史话术、直播文字记录、简版线稿、团队成果及重建示例继续使用来源限定，未新增个人确认、归因数字或产品结论。

## UI与排版

- 暖底、深绿、宋体标题、正常可读正文及来源图注分层延续既有方案。作品提前进入案例开篇；原句成为视觉重点，解释保持正文。
- 桌面使用简洁侧栏；手机只有一条案例栏常驻。海报对照在手机上下阅读，保留比例与原图入口。低清成片使用小幅视频，不放大为高清主视觉。
- 八页在320／390／1280px同源iframe中未发现横向溢出，实际内容宽度约305／375／1265px。检查的是实际浏览器排版，不是PNG／SVG静态图；未模拟真机触控或Safari。
- 修正了程序化章节焦点出现整段黑框的问题，链接、按钮、summary、视频的键盘焦点样式仍保留。

## 剩余边界

真实手机触控、Safari、网络差时的大文件打开及招聘读者试读尚未覆盖。视频仅验证逐条开始播放和互斥，没有宣称逐条完整播放。自审不能证明内容已经优于原版或候选人认可最终口吻。

本轮只提供新的独立预览；正式入口替换仍依现有约定处理。实际部署结果以项目状态和发布PR为准。
