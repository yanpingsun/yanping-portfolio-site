# 通用版 HTML r2 独立预览

本轮把分别修订和自审的内容r4、UI／UX r3接入实际网页。案例保留连贯主叙述，以概览、策划与作品、结果与贡献、完整作品四项导航支持来回阅读；酷狗使用主要任务／工作范围。手机只保留一条常驻案例栏，补充作品具名展开，最多一层。

八份文稿继续以 `content/proposals/general-r4/` 为源，未覆盖原七份r3稿。生成方式：

```bash
python3 tools/build_general_preview.py --refined
```

`data.js`与六张视频截帧由工具生成；正文、原件和视频不另写一份。`app.js`与`styles.css`负责展示及交互。原作品复用根目录资源，六张低清视频预览沿用已记录的真实截帧。

新版路径为 `/preview/general-r2/`。现有 `/preview/general/` 和正式根入口继续保留，发布仅新增本目录，不修改旧页面或原素材。完整源码、输入稿及验证记录在工作分支评审；发布PR只包含本目录。

本地浏览器已检查桌面、320／390px框架中的正文、资源和布局，14组旧海报链接、11条视频的开始播放与互斥、手机目录、补充资料返回及原图查看。框架内可用内容宽度分别约305／375／1265px，包含传统滚动条；不等同于真机Safari。详见 `docs/HTML-R2-REVIEW.md`。
