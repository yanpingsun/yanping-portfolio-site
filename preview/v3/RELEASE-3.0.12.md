# 3.0.12：首页与精华油案例精简

日期：2026-11-09。基于最新main（e97a201），保留huhaheng完成的新域名、HTTPS与EdgeOne配置。

## 内容与排版

- 首页删除口号、能力介绍区及重复数据块。直接说明职业、经历、求职方向，接着展示项目。
- 项目卡用真实海报、活动页面和内容合集，标题写明项目与工作类型。旧生成导航封面及源文件保留，作品目录暂不重排。
- 精华油职责统一为“卖点提炼、海报文案与信息层级、公众号文章、视频脚本”，页面及脚本分析开头不写脚本数量。
- 精华油按项目介绍、海报文案与信息层级、公众号文章、视频脚本、项目结果、更多作品排列。删除重复的挑战、协作与方法总结段落，分工集中在首屏。
- 手机默认展示海报成品，排版线稿按需展开；桌面初始展开线稿。旧线稿深链接仍自动打开对应内容。
- 精华油视频卡片在手机上单列显示原封面、名称、简短说明、观看及分析入口，名称只出现一次。原视频、原PNG及分析正文保留；脚本分析标题改名并兼容旧标题锚点。
- 其他案例正文、统计口径、9个有效视频地址、全部封面、简历及原素材不改。

## 维护入口

- `app.js`：首页`homePage`、真实作品卡`featureCard`、精华油`oilCasePage`。
- `data.js`：精华油作品文字与补充阅读；脚本分析开头及旧标题别名。
- `content.js`：精华油摘要、职责。
- `styles.css`：本版样式限定于`.home-direct`、`.oil-direct`，其他案例沿用原排版。
- `index.html`及`app.js`资源缓存参数更新至3.0.12。每次改运行文件须更新ASSET-MANIFEST.json后构建。
