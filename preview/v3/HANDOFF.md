## 各文件改什么

| 修改内容 | 文件 |
| --- | --- |
| 首页、作品目录、关于页的文字与结构 | app.js 中的 homePage、worksPage、aboutPage |
| 各项目首屏标题、摘要、职责、数据、关键判断、协作分工、结果与方法 | content.js 中的 PORTFOLIO_V3.cases |
| 案例详细叙事、原件入口、补充作品、13份分析正文 | data.js 中的 GENERAL_PORTFOLIO.pages 和 materials |
| 五案通用排版、目录、折叠、原图弹窗、视频、阅读位置 | app.js 中的 casePage、block、figure 与路由/事件逻辑 |
| 字号、颜色、留白、图片高度与手机适配 | styles.css |
| 页头页脚、页面元信息、脚本样式入口 | index.html |
| 下载简历 | assets/resume.pdf |
| 六张已有视频截帧 | assets/ 中的 WebP 文件 |

首页等页面由 app.js 的专用模板渲染；仅改 data.js 内旧的首页/关于页内容不会同步改变这些模板。详细内容的数据结构保持不变。

data.js 是在 general-r2 基础上复制到 3.0 的独立文件，并非实时读取 general-r2。后续不能只修改旧版数据并假定 3.0 自动同步；也不要用旧版生成结果直接覆盖 3.0 的全部实现。若需要同步，应核对两个版本的差异。

## 内容目标

面向内容营销经理或内容团队组长，呈现产品内容策略、多渠道组织、已有团队管理与跨部门推进经验。

- 精华油：代表产品内容主线、渠道适配与脚本能力。
- 酷狗：代表两名专员的管理、内容审核、资源沟通及持续活动/栏目。
- 面膜、防晒、洁面：分别补充升级沟通、价值与顾虑回应、产品主张及信息层级。
- 视觉沿用米白、深绿、砖红和编辑式排版，正文优先保证阅读舒适。

## 已采用的事实口径

- 酷狗整体引流项目：累计引流256万人次，拉新21万名纯新增用户。整体项目与单期发糖机分开；人次与人数分开，不相加或计算转化率。
- 256万人次采用2026-11-02最新确认，优先于旧页面200万+的概括。
- 发糖机历史阶段：累计参与8万人次，拉新及促活2.2万人次，不归为时代少年团某一期的成绩。
- 精华油：上市两周私域GMV 460万+；防晒：上新半个月私域GMV 120万+；面膜：上新GMV 100万+；洁面：上新GMV 80万+。均为团队及渠道的项目整体成绩；面膜、洁面的统计时长未补充。
- 酷狗管理两名专员，独立负责微博内容与活动，其他平台以统筹、审核为主。预算管理、招聘、绩效体系及具体转化提升幅度未补充。
- 护肤品视觉由设计师完成；视频拍摄、剪辑、商务按已有分工说明。保留历史原作与后期重建示例的区别。

如用户后续补充或更正事实，以新的明确确认更新相关页面与简历，并检查同一数字出现的所有位置。

## 素材与发布

原图、11条视频、公众号PDF和线稿继续引用仓库已有素材。路径通过相对地址 ../../ 指向仓库根目录；仅拷贝 preview/v3/ 不能获得完整离线素材站。保持这些相对路径；如以后要切换为正式首页，需要重新调整资源根路径。

这是静态HTML/JS网站，无依赖安装或构建步骤。将修改提交到 main 后，由已有 GitHub Pages 流程发布，确认对应提交的 pages build and deployment 成功，再核对在线页面。

当前 index.html 为脚本和样式使用 ?v=3.0.1。更新文件后建议同步修改版本参数，避免浏览器继续使用旧缓存。
