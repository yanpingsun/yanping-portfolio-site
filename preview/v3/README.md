# 孙岩萍内容营销作品集 3.0

独立地址：`/preview/v3/`。沿用 GitHub Pages 托管，新增本目录；根入口与 general / general-r2 预览均保留。

## 内容与设计

- 沿用原版米白、深绿、砖红及编辑式排版，提高正文阅读性。
- 首页突出产品内容策略与团队管理：精华油、酷狗为两大代表项目；面膜、防晒、洁面补充不同判断。
- 五个完整案例均包括关键判断、作品、协作与交付、项目结果与方法、补充原件。
- 桌面侧边目录、手机常驻章节栏；补充作品具名展开；原图支持缩放；视频支持原文件入口。

## 事实与素材

内容综合正式2.0与 general-r2 的真实作品及分工说明。酷狗整体引流采用本地《酷狗作品集内容.md》2026-11-02最新确认：256万人次、21万名纯新增用户；保留整体项目与发糖机阶段数据的区别，不计算转化率。

护肤品GMV均为团队及渠道的项目整体成绩；面膜、洁面的统计时长不自行补写。管理职责限定为已确认的两名专员及内容审核、资源沟通；未新增预算、绩效、招聘或转化提升等未经确认的事实。

`data.js`复用 general-r2 内容及13份补充分析，`content.js`为3.0导读与案例摘要。原图、11条视频、公众号PDF与线稿继续引用仓库既有素材。`assets/resume.pdf`为本地最新简历副本；六张视频预览为已有真实截帧。

## 维护

无构建步骤。修改 `content.js`中的摘要与分工，或 `data.js`中的详细正文；`app.js`负责路由、原图和阅读位置，`styles.css`负责响应式布局。发布只需新增本目录。
