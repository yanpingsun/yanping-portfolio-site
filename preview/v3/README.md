## 内容与设计

- 沿用原版米白、深绿、砖红及编辑式排版，提高正文阅读性。
- 精华油与酷狗首页及目录封面统一为4:3浅暖灰画幅与一致留白：精华油用双瓶与主标题，酷狗用品牌与平台矩阵。案例内可继续查看原始作品。直播分析已移除片段时码。
- 首页突出产品内容策略与团队管理：精华油、酷狗为两大代表项目；面膜、防晒、洁面补充不同判断。
- 五个完整案例均包括关键判断、作品、协作与交付、项目结果与方法、补充原件。
- 桌面侧边目录、手机常驻章节栏均支持返回顶部；手机目录点击后自动收起。
- 9条可展示产品视频按用户文件名接入真实封面，人物、产品和文字完整显示；封面可放大，原视频和脚本分析分别保留。对应关系见 [VIDEO-COVERS.md](VIDEO-COVERS.md)。
- 公众号使用原文入口并在新标签打开，保留能说明内容策略的精选截图。
- 首页、项目目录与案例首屏统一4:3外部容器，同类产品图使用相同正方形展示位；面膜按产品主体取景，其余产品等比显示，完整照片仍可放大查看。
- 各案例以海报线稿与成品、公众号文章、视频脚本等明确标题分区，线稿对照图上方标明“内容线稿／设计成品”。
- 面膜直播仅保留升级讲解、生活化比喻两张重点截图，保留讲解分析，删除全部截图列表。
- 入梦晚安电台主海报改为单依纯；新增2021.02.06—2021.10.13栏目全期拉新60,590人、拉活71,999人的独立指标及原始数据记录入口。

内容综合正式2.0与 general-r2 的真实作品及分工说明。酷狗整体引流采用本地《酷狗作品集内容.md》2026-11-02最新确认：256万人次、21万名纯新增用户；保留整体项目与发糖机阶段数据的区别，不计算转化率。

根据用户2026-11-04最新确认，四个护肤品项目统一为上新首月GMV：精华油460万+、防晒120万+、面膜100万+、洁面80万+。保留精华油与防晒的私域渠道范围，以及团队及渠道共同完成的项目口径；网站下载简历也已同步。管理职责限定为已确认的两名专员及内容审核、资源沟通。
