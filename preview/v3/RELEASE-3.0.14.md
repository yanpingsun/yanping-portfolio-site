# 3.0.14：海报与线稿对齐修复

日期：2026-11-09。基于3.0.13，用户指出成品和线稿没有对齐。

运行源码提交：83713139e4fa6010ce8da0b39b06acd53aec7a87。

## 原因与修改

右侧线稿比成品多一层summary、内边距与重复“内容线稿”标签，主展示区测得图框顶部低65.25px。此前检查没有覆盖并排图框几何位置。

统一两侧38px标题区，summary直接作为线稿标题，移除线稿内部重复标签和额外边框／内边距；保持相同宽高图框。原图以contain完整显示并顶端对齐，说明文字预留相同高度，使原图链接也对齐。

手机继续单列展示，线稿可收起、展开与放大。未裁切、拉伸或编辑原图片，未修改已确认文案、视频、分析或任何素材文件。

- 四款产品14组成品／线稿在900和1280px下逐组测量，共28组：图框顶部、宽高、说明与原图链接的偏差均为0。
- 320和390px下四案展开状态共8组：单列、无横向溢出、图片contain、无重复线稿标签。
