## 来源与边界

网页中能直接观察的安排、从固定源码读取的行为，以及我们对它为何这样组织的解释分别标注。不能仅凭现有页面断言作者做过哪些用户研究、为什么作出某项选择，或已证明某种布局更有效。

原版事实表述原样保留用于比较，不自动替换[当前事实核对记录](../content/evidence.md)。例如酷狗数字的周期／定义仍待核对；归档原文保留数字不意味着新稿应无条件恢复。原站截图也保留作品当时的传播表达。

资源复用现有目录，没有复制整库。当前共核对105个被页面引用的本地资源，字节与固定原版一致；原版正文的673段含中文文本均在转录中保留。这些数字用于检查还原覆盖范围，不是内容质量评分。[媒体与来源索引](media-index.json)保留固定 blob、引用页面和结构清单；将来原件变化时以固定提交为准。

## 重建方式

在仓库根目录运行 `node baseline/tools/extract-original.mjs`，需要 Node.js 和 Python 3 标准库。它只读取固定提交的既有模板与内容，在内存中还原正文并生成 Markdown／索引；不运行网页路由事件，不生成 HTML、CSS 或新原型。生成器会核对中文文本片段是否保留，并检查引用资源是否仍与固定原版一致。内容策略、UI/UX 观察和比较结论由人工维护，不用生成器推测作者意图。
