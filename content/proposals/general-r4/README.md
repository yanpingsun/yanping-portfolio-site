# general 内容 r4 提案

日期：2026-11-02。独立的内容工作区，沿用[通用定位](../../brief.md)及[证据说明](../../evidence.md)。这是内容r3后的编辑提案，不是新的投递版本；网页仍使用原稿，未运行数据生成或发布。

## 内容方案

文稿同时支持扫读和细读：标题与要点给出具体判断；紧邻的正文解释背景、原因、本人行动与对应证据；完整资料有明确去向。评审时先读文稿本身，暂不依赖颜色、字号或视觉包装。

1. 背景、职责与整体成果集中说清。必要的核心事实可在开篇与成果章节复现，允许独立进入章节的读者准确理解；删的是没有新增信息的重复解释。
2. 每段说明补充作品看不出的判断。只复述“上方有标题、下方有三组信息”的文字，压成图注；具体用词、信息优先级及渠道改写保留。
3. 优先展示候选人写过的原句及真实交付，让方法紧贴证据。不同案例依各自的内容问题展开，不套统一的长渠道清单。
4. 个人职责和成果范围保持可见。一般历史作品说明可集中交代；后期重建、成片分析与团队制作等关键身份仍贴着对应材料。
5. 主叙述先形成完整认识，补充阅读保留独特能力证据和原件。每次移动作品都说明理由与新位置，不把“文件还在仓库”当作展示入口已保留。

整批七份页面的逐页方向见[总方案](../../../docs/REFINEMENT-PLAN.md)。本轮先完成两种内容任务的试点；首页、关于、防晒、面膜、洁面的r4正文尚未改写。

## 独立试点及阅读方法

- [精华油完整提案](oil.md)：共同主张、日夜对照、长文和讲述方式；完整图文、四条成片与后期重建入口全部保留。
- [酷狗完整提案](kugou.md)：活动参与、音效内容与持续栏目；全部平台证据及分项范围保留。
- [内容review与调整记录](../../reviews/general-r4-pilot-review.md)：检查内容逻辑、事实、重复和作品覆盖，独立于设计评审。

各稿“网页正文”包含主叙述及明确命名的补充阅读；编辑依据另列。设计可以将后者组织为清楚的补充查看入口，但不能把主要论证移走、把重要身份变成难读小字，或悄悄删掉正文。设计图使用的稿件校验值另记录，文字变动先回到这里。

## 内容 review 的检查范围

- 只读每个要点，是否能正确理解这一案的任务、判断与个人贡献？
- 阅读解释和作品，是否真的补足原因、过程和结果，能用于面试追问？
- 两个主案的差异是否清楚，是否仍有空泛的方法术语或重复总结？
- 原版／r3的独特证据、全部原件入口是否都有明确位置？
- 角色、数据时段、历史作品和重建身份是否与现有来源一致？

本轮不新增调研、测试日志、结果归因或本人确认。文稿自审完成不等于候选人认可最终口吻，也不等于招聘读者已验证内容效果。
