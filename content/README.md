# 通用基准版内容稿

版本 ID：`general`。日期：2026-11-01。阶段：精华油已形成单案内容 r3，其余六份页面稿仍为 r2，继续与原版完整内容校准，尚未接入网页。编辑自查不代表已证明改版更好。

用户已确认先做通用基准版。本轮依据仓库现有 CV 与项目材料，保留产品内容策划、新媒体运营两条能力线；不针对某一岗位定制。CV 是否最新、事实差异和首稿措辞仍需核对，案例排序可随反馈调整。

先看[精华油完整内容 r3](projects/oil.md)及[与原版的逐项对照](reviews/oil-r3-vs-baseline.md)，可并行阅读[原版完整案例](../baseline/pages/projects/oil.md)。本轮补回三组海报对照，保留全部原版核心作品入口，再调整表达和材料身份说明。内容直接在 Markdown 中维护，不另外制作报告 PDF；原有作品 PDF 继续引用。

全站依据见[原版内容与UI/UX基线](../baseline/README.md)及[初轮对照](../baseline/comparison.md)。原版已有职责、策略、作品分层与扩展入口；防晒视频／话术、面膜视频／直播、其他案例海报对照和部分平台作品的去向仍需补齐，不能把原件仍在仓库等同于新稿已经保留展示。

## 先读什么

1. [定位与取舍](brief.md)：这版给谁看、要证明什么、为什么这样选案例。
2. [首页](home.md)与[关于我](about.md)：可直接阅读的网页文案。
3. 两个主要案例：[日夜精华油](projects/oil.md)、[酷狗音乐](projects/kugou.md)。
4. 三个补充案例：[童颜面膜](projects/mask.md)、[高客单防晒](projects/sun.md)、[逆时光洁颜霜](projects/cleanser.md)。
5. [证据与待核对事项](evidence.md)：能力与作品的对应关系、数据口径及本轮处理方式。

各页面的“网页正文”是准备进入网站的内容；“编辑依据与呈现说明”供协作者使用，不进入网页正文。图注属于网页内容，源码路径仅用于查阅和接入。

## 当前的主要取舍

- 精华油展示从产品信息到长文、短图文、脚本的内容组织；酷狗展示活动机制与平台协作，两者共同支撑通用定位。
- 面膜、防晒、洁面分别围绕升级价值、价格与肤感顾虑、短文案提炼展开，篇幅按代表性区分。
- 首页先让读者看懂能力与作品，案例内再呈现有明确范围的成果数字。
- 保留历史作品、个人贡献和项目整体成果的区别；重建稿作为补充，不当作原始交付。
- 酷狗引流数字的统计范围尚未齐全，第二轮正文先展示作品和分工，原数字继续留在证据记录与 r1 归档中。
- 案例结尾补齐互补案例或简历入口，具体导航形式留到 UX。
