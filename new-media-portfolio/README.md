## 核查口径

- 酷狗累计引流**256万人次**，客户端**21万名纯新增用户**；整体项目数据，含拉新与促活，人次与人数不相加。
- 胖汪发糖机累计**8万人次参与、2.2万人次拉新及促活**；不能当作2022年某单期成果。
- 逆时光颜研究院**53条原创视频、3.1万+粉丝、60万+转发收藏**均为账号留存/累计指标。
- 小红书展示三篇本人参与撰写的已发布笔记。数值为 2026-11-25 公开互动快照，独立于项目转化。帅姐不帅 Amber 的视频列为公开笔记参考。
- 精华油/防晒/童颜面膜/洁颜霜GMV，均为**上新首月的项目/渠道整体成果**，不是某条内容的独立转化。
- 微博个人主责，酷狗其他平台统筹/审核；抖音制作剪辑、APP技术、视觉设计由对应成员承担。

## 源码与资源

`index.html` 是独立、可编辑、响应式的静态网页：14页纵向浏览；顶部章节导航；点击图片可查看 GitHub 原作品。页面内原图直接链接现有仓库的历史图片，**没有复制生成式图片来冒充历史素材**。

目前还未额外上传PDF版本。可在浏览器中使用打印/另存为PDF进行预览；最终导出以成品排版核对后为准。
