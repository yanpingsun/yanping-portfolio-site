# 防晒精选素材与展示顺序

更新日期：2026年10月27日。

完整叙事见[项目审阅稿](project.md)。本清单把现有代表素材与案例中的策划动作对应起来，作为后续作品集排版的选材依据。以下顺序为作品集讲述顺序。

## 项目叙事顺序

项目概述与简历成果 → 用户疑问与个人职责 → 护理价值、轻薄体验及渠道分工 → 公众号 → 朋友圈 → 私域话术 → 详情页 → 两条主展示视频及更多案例 → 项目成果与个人贡献。
