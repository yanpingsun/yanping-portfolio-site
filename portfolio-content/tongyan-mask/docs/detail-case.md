# 商城详情页｜解释王牌产品升级，组织购买所需信息

童颜面膜是在镇店王牌胶原炮基础上升级配方、增加美白淡斑方向的产品，并按新品流程开展上市内容策划。胶原炮已有成熟的用户认知，详情页需要在承接旧品认知的基础上，解释童颜面膜的新价值，为用户选择新版建立具体理由，同时让首次接触产品的人理解产品特点与护理方式。

我负责淘宝／天猫详情页的整页文案、内容结构与信息顺序，设计师负责视觉设计和制作。

## 从护理困扰带出产品价值

页面以“美白抗皱产品没少用，却还是没效果？”开篇，结合暗沉、皱纹、色斑和松垮等外观困扰，让读者先建立需求关联，再进入产品介绍。

随后的1.0与2.0对比，从科技、配方、护理方式及功效方向展开，集中解释新版与旧版的区别，让“升级”有具体内容。

## 将技术、组件和成分分层讲清楚

技术部分通过图示和对比组织信息；产品配置部分分别介绍白膜、金膜和面霜，将多组件转成有先后的护理过程，解释组合使用的价值。

成分部分按美白、抗皱等护理方向展开，并为原料搭配利益标题。读者可以先理解与自身需求有关的作用方向，再阅读成分细节，减少记忆原料名的负担。

这套详情页将原本分散的升级资料、技术介绍、成分信息和使用说明，整合为从需求识别到购买判断的连续阅读过程。它体现了我在产品卖点转译、整页内容策划与信息顺序安排上的工作。
