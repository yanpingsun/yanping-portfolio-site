# 童颜面膜｜各渠道内容分工与作品集表述

整理日期：2026-10-22。依据用户本次补充、此前确认的职责与已收作品整理。


## 二、作品集可用正文

### 围绕升级价值，按渠道组织内容

胶原炮已有成熟的用户认知。童颜面膜按新品流程上市，需要在承接旧品信任的基础上，让用户理解新增价值，并形成选择新版的理由。

我围绕这一目标，根据不同渠道的阅读场景、信息承载量和互动方式，组织完整介绍、主题种草、故事化表达、实时讲解、购买信息展示与销售沟通。

| 渠道 | 核心内容任务 | 内容组织方式 |
| --- | --- | --- |
| **公众号：建立完整新品认知** | 让用户理解产品特点、护理组合与核心价值，形成对新品的整体认识 | 通过长图文串联需求、产品特点、技术与成分说明、护理组合及使用体验，组织标题、正文和配图文案，形成连贯的阅读顺序 |
| **朋友圈：拆解购买理由，分主题种草** | 让用户每次接触内容时记住一个明确卖点，逐步理解新品价值 | 将复杂信息拆成升级差异、安心美白、效果诉求三个主题。配文突出切入点，图片展开对比、资料或效果表达，形成主次分明的图文配合 |
| **明星／达人视频：以人物和场景建立代入感** | 让用户愿意继续观看，并把产品与自己的生活和护理需求联系起来 | 根据合作对象的表达特点，从片场状态、情绪困扰、夫妻日常等故事入口展开，再通过情节或人物态度转入产品。完整撰写脚本，并与达人沟通成片表达 |
| **直播间话术：降低理解门槛，承接实时购买判断** | 让观众快速听懂新旧差异、技术概念和使用价值，跟上讲解节奏 | 参与讨论并制定产品讲解话术，利用新旧对比、生活化比喻、演示安排和互动提问组织信息，将抽象资料转成容易听懂、便于观察的表达 |
| **商城详情页：集中呈现购买所需信息** | 让准备购买的用户能够自主查阅、比较，并理解选择新版的理由 | 以需求引入、新旧对比、技术与组件、成分分组、支持材料、保存及用法组织整页内容，使分散的产品资料形成连续的阅读结构 |
| **私域销售话术：按具体需求回应疑问** | 支持销售针对个人关注点解释产品，连接卖点与实际护理需求 | 按肤色、细纹、使用方式等不同问题组织沟通内容，选择相关卖点、资料和使用说明，帮助销售有针对性地解释升级价值与使用安排 |

这一分工体现的是信息取舍：长内容帮助用户系统了解产品，短内容突出单一购买理由，视频通过人物与故事建立关联，实时沟通则根据疑问补充解释。各渠道可以共用核心卖点，同时采用适合自身场景的展开方式。
