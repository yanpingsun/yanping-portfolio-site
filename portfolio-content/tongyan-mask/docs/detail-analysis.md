## 三、按页面顺序分析

| 模块与位置 | 页面实际内容 | 回答用户什么问题 | 内容组织的作用 |
| --- | --- | --- | --- |
| 1. 第一张开头：护理困扰 | “美白抗皱产品没少用，却还是没效果？”配暗沉、皱纹、色斑、垮脸四类画面 | 这款产品与我的问题有什么关系？ | 用多个可识别的外观困扰建立关联，先让读者找到自己的需求，再进入产品说明 |
| 2. 第一张：项目顾虑及产品出现 | “想做美白抗皱项目，又怕痛？怕没效果？”“灵感来自胶原炮＋光电项目”，随后出现产品与“不破皮、促胶原、抗皱紧致、淡斑美白” | 我为什么会考虑这种护理方式？ | 先提出对项目的顾虑，再推出居家使用的面膜，制造替代性想象。通过项目顾虑到居家产品的转场，建立护理体验与产品价值的关联 |
| 3. 第一张：2.0与1.0比较 | 按科技、配方、方式、原理、功效五行对比 | 我了解旧品，新版究竟改在哪里？ | 将分散的升级信息放进同一对照框架，降低老客理解差异的成本。成分和新增美白淡斑方向是更适合保留的解释重点 |
| 4. 第一张：专利及研发信息 | 专利证书；16位博士、3年、8000次、10000＋次等页面数字 | 技术有什么来历？ | 用资料画面和研发信息承接升级主张。证书证明范围及数字出处仍需逐项对应，不能由证书推出全部功效成立 |
| 5. 第一张：渗透科技2.0 | 皮肤层次示意、箭头、1.6倍、99%、3倍等 | 所谓技术升级怎样理解？ | 把抽象机制做成方向、层次及数字对比，便于快速抓住“吸收”这个关键词；同时也容易形成超出化妆品范畴的理解 |
| 6. 第一张：专利双膜设计 | 白膜40ml、金膜及42℃热导表述 | 双膜分别做什么，为什么需要组合？ | 先拆分组件，再说明联合使用价值，帮助读者理解产品形式的差异，避免只看到比普通面膜更多的步骤 |
| 7. 第一张：3步加乘 | 童颜面膜、超导发热金膜、童颜霜 | 我买到的是怎样一套护理？ | 把多件产品解释成有先后的护理过程，并让面霜的存在有内容承接；需与真实盒内配置和标签用法统一 |
| 8. 第一张：真人实测及分期数字 | 第一次、14天、28天分别搭配不同指标 | 我可以关注哪些变化，多久观察？ | 时间与指标并列，使结果更具体。但各阶段测量的不是同一指标，不能读成同一效果逐级增长，也不能直接转成个人效果承诺 |
| 9. 第一张：抗氧、蛋白相关图像 | 依克多因／麦角硫因相关说明；DAY 0与DAY 28图像及多个百分比 | 成分与抗皱方向怎么连接？ | 由成分解释接到研究图像，构成“为什么这样配”的说明。需要区分原料研究、实验模型和成品人体评价 |
| 10. 第一张后段及第二张开头：美白部分 | AA2G、烟酰胺、光果甘草根、α-熊果苷、凝血酸；注册证；VISIA对照 | 新增美白淡斑价值怎样展开？ | 给成分配上利益标题，并用注册及测试画面承接。新增美白方向在页面上获得了独立篇幅，区别于仅在旧抗皱卖点后加一句“还能美白” |
| 11. 第二张：抗氧与抗皱体系 | 依克多因、麦角硫因；玻色因、三重胜肽、重组胶原蛋白肽；88%／90%／95%认同及局部前后对照 | 对皱纹、饱满和轮廓的护理怎样说明？ | 将原料按护理方向组织，再用眼下纹、法令纹等具体部位呈现；消费者认同、仪器指标、照片应分别解释 |
| 12. 第二张：45分钟与普通面膜对比 | “15分钟普通面膜”与“45分钟鲜活胶原灌注” | 为什么使用时间更长？ | 用对照解释时间成本，尝试将“耗时”转换为护理差异。通过时长与护理示意对比，将更长的使用时间连接到产品体验 |
| 13. 第二张：报告与安全 | 检测报告、“安全短保”、无菌生产说明；多个“0”；“敏肌放心用” | 没有防腐剂如何保存？是否适合我？ | 将配方特征、保存和适用顾虑集中回应，使安全信息成为购买判断的一部分。但不同检测不能互相替代 |

## 四、适合在作品集中展示的内容能力

### 1. 同时照顾老客与首次了解产品的人

首屏从暗沉、皱纹、色斑、垮脸切入，给首次了解产品的人一个阅读理由；紧随其后的1.0与2.0对比，则照顾了解胶原炮的老客。两类读者不需要具备相同的产品知识，也能找到入口。

这是从页面结构作出的分析，不代表已经获取新老客阅读或转化数据。

### 2. 将复杂资料转成不同层级的信息

页面形成“大标题讲需求或利益—小标题讲组件／成分—图像和证书补资料”的层级。比如“联合使用”之后拆出白膜与金膜，“3步加乘”之后加入面霜；成分区则用“亮肤”“色沉”等易理解的词承接原料名。

可展示项目本人负责的是信息分组、标题及文案衔接；画面设计与制作属于设计师。

### 3. 不只列成分，还解释组合价值

成分被分到抗氧、美白、抗皱等方向，面膜和面霜被放进护理步骤。这比单独陈列原料名、证书和产品图更有阅读关系。分析可以强调这种组织方式，同时指出原料功效与成品结果仍须分开。

### 4. 在长页面中回应不同购买疑问

新旧对比回应“为什么升级”，成分和技术回应“有什么不同”，数据与资料回应“有什么依据”，保存和用法回应“适不适合、怎么用”。这是详情页比单条朋友圈更完整的内容任务。

未提供详情页停留、加购或成交数据，不写成已证实提升转化。
