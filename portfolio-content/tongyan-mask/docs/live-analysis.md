# 童颜面膜｜抖音直播话术截图整理与产品讲解分析

整理日期：2026-10-22。依据8张产品讲解和3张补充下单引导截图整理。


## 二、作品与个人职责怎样对应

已确认个人职责：**参与直播间话术讨论，并制定抖音直播间话术，非主播稿。**

本组素材是主播直播视频文案的文字记录截图，带说话人、时间和转写痕迹，可呈现直播中的实际表达。它不等于用户原始交付稿，不据此声称主播全程逐字由用户独立撰写，也不把自动转写当成无误的逐字实录。

作品集可以用“参与讨论并制定话术”的已确认职责，搭配“直播呈现节选”与“内容逻辑分析”。下文对表达作用的解释是本次分析，不假定每个比喻均是用户独创。


## 三、产品讲解的主要顺序

截图所见的内容推进大致是：

**承接旧品认知 → 提出多种肌肤困扰 → 说明新版增加的护理方向 → 用比喻和演示解释技术 → 讲双膜用法 → 展示效果及资料 → 说明价格与套组。**

这是一段产品讲解与销售说明交织的直播内容，不是完整直播录像。截图时间有间隔、上下边缘有截断，不能把这一顺序认定为完整场次SOP。

作品集可重点保留前五项：展示如何把产品资料变成观众听得懂、跟得上的讲解。促销部分少量补充即可。


## 四、具体表达与内容逻辑

| 截图中的表达或动作 | 回答观众的什么问题 | 为什么这样讲容易理解 | 展示时怎样处理 |
| --- | --- | --- | --- |
| 产品讲解01，00:53：“不仅脸上长皱纹了，同时还伴随着松垮垂，甚至肤色不均匀了，脸上斑斑点点的了。”随后对比1.0与2.0的护理方向 | 旧品已经很好，为什么还要升级？ | 先列举观众认识的脸部困扰，再说明新版的美白祛斑方向；升级由用户需求带出，而非直接罗列新成分 | 最适合做开头节选。升级事实仍依据已确认配方变化和新增美白淡斑特证说明 |
| 产品讲解02，01:29段：“就像葡萄没有水分，是不是就变成葡萄干了？” | 抽象的状态变化究竟意味着什么？ | 用饱满葡萄与干瘪葡萄干的形象，帮助观众形成对饱满、干瘪和纹路的直觉 | 分析其比喻作用；不把葡萄变化当作人体衰老机制的证明 |
| 产品讲解03，03:01段：“这是两块猪皮，它就是来模仿人体皮肤结构的。”“同样的时间，同样的手法”“别眨眼，3、2、1，走。” | 所谓渗透技术有什么可看的区别？ | 将抽象技术安排成对照演示，并提示观众何时集中注意力，让讲解有观察对象 | 现有证据是文字截图；不能写成本次已看到演示实物或验证了人体渗透结果 |
| 产品讲解03，04:29后：“啥概念？”接“比你的头发丝还细，比你的毛孔还要小1/10000……” | 数字很小，但到底小到什么程度？ | 先用“啥概念”承接疑问，再用头发丝、毛孔等熟悉事物建立想象 | 原句有截断，仅摘录可见部分。道尔顿表示分子质量，该比喻不作为精确尺寸换算；旧话术90道尔顿与当前包装口径分开记录 |
| 产品讲解04：白膜25分钟，再覆盖金膜20分钟 | 产品具体怎么用，双膜有什么操作顺序？ | 用步骤与时长让观众想象实际护理过程，把结构信息转成可执行的使用说明 | 当前说明以包装为准：白膜25分钟后不揭下，覆盖金膜20分钟，总计45分钟；盒内含面霜，面霜按包装使用 |
| 产品讲解06，07:48段：“不仅有抗皱的矩阵成分，还有美白祛斑的矩阵成分，另外还添加了修护的矩阵成分。” | 多种成分分别对应什么需求？ | 按抗皱、美白祛斑、修护分组，不让观众记一长串原料名 | 作为功能分组的讲解例子；各项实际功效仍需对应产品资料，不由主播口述单独确证 |
| 补充下单引导02，17:12段：“姐妹平时你想要这三个效果，去外面面膜要买三种吧？” | 一个产品提供多种护理方向，对我有什么价值？ | 将多种功能转成购买和使用场景：由“有三类成分”推进到“为什么考虑这款产品” | 此句出现在促销阶段，可用作产品价值解释的补充；不认定实际可替代任意三种产品 |
| 产品讲解07，08:44段：“重点看泪沟，看法令纹，看两边脸的肤色。” | 展示效果时，我该看哪里？ | 指明观察部位，比笼统说“效果好”更容易跟上；把注意力集中到纹路和肤色 | 当前只看到指引文字，不能据此认定前后变化、因果和维持时间 |

这些表达体现出四个可以写清楚的内容工作：先解释升级与用户需求的关系；用熟悉的事物帮助理解抽象概念；把技术讲解组织成可观察的过程；把多种成分按护理需求和使用步骤重新排序。


## 五、互动与下单部分怎样补充

产品讲解05，07:35，副播说“老板，他们想看粉丝效果图。”这是截图里明确出现的一次观众需求转述，可分析直播如何由讲解转向效果展示。没有问题统计，不写成“高频用户需求洞察”。

补充3张主要包括：重复1号链接与到手数量；比较一单、两单及赠品；区分新粉尝试与老粉囤货；倒计时和名额提示；7天无理由、保价及一对一使用指导的口头说明。这些是该场次的历史销售表达，不作为当前价格、活动或服务承诺。

因此，已有资料足以说明产品讲解之后接有下单引导，不需要再补一份促销稿才能完成本模块。没有直播成交、转化率或归因数据，不用“显著提升转化”等结果句。


## 七、作品集展示建议

优先选四类节选：①旧品到新版的升级理由；②葡萄比喻；③猪皮对照演示的话术安排；④按抗皱、美白祛斑、修护分组并转为使用价值。篇幅允许时，再补双膜使用步骤和观察部位指引。下单引导放在末尾作为小幅补充。

可用说明稿：

> 参与童颜面膜直播间话术讨论与制定，围绕旧品升级、多种护理需求和双膜使用方式组织产品讲解。直播呈现中，通过新旧对比、生活化比喻与对照演示的讲解安排，帮助观众跟上较抽象的技术说明；再将成分信息按抗皱、美白祛斑、修护分类，连接到用户关心的护理需求。所附为主播直播文字记录截图，展示话术在直播中的呈现。

以上为本次整理的展示说明，不冒充历史交付稿。可与公众号、朋友圈、三条视频模块合并进入完整项目稿。
