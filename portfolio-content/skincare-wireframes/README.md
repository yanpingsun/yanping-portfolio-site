# 护肤四品类海报线稿

童颜面膜、防晒、精华油、洁面：每款 1 张主海报 + 1 张卖点页，共 8 张单页线稿，另附 1 张整组总览。

当前素材为创意线稿提案；产品轮廓与待填文案用于版式展示，后续展示页可据正式资料补充。
