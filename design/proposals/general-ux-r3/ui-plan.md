# UI视觉方案：让真实作品与表达有分量

2026-11-02。输入文稿见[内容提案](../../../content/proposals/general-r4/README.md)，视觉只处理表达层级，不自行改字或扩写事实。

## 视觉方向

保留原版暖底、深绿与宋体标题的基础，用更明确的作品面积、字体层级和图文关系呈现内容策划岗位的专业性。作品是主要视觉材料，装饰保持克制；通过真实原句、内容线稿与成品、具体参与路径体现表达、审美和用户理解。

基础配色沿用：背景#f6f4ef，标题#26382f，正文#46534a，辅助字#626c62，强调色#a65336，分隔线#cdd2c7。作品保留原色，不逐页新增一套主题色或给原图重画文案。

标题、原作文案与正文分出优先级；正文和关键限定保持清楚可读，辅助色主要用于日期、来源、图注等。静态稿以桌面18px、手机17px正文为工作值，标题按内容与宽度分级；不以压小字号解决内容过长。

## 基本呈现形式

| 内容 | 视觉处理 | 表达的工作判断 |
| --- | --- | --- |
| 案例开篇 | 简短身份与主张、大幅真实作品、相邻的职责和结果范围；手机优先让作品进入首屏 | 候选人做什么、拿什么证明 |
| 原作文案 | 用少量字号、字重和留白突出原句，解释仍用正常正文 | 文字提炼，而非只介绍自己会写文案 |
| 线稿与成品 | 同组明确配对，标签区分身份，说明点出取舍；手机允许顺序阅读，原图可进一步查阅 | 内容结构与视觉协作，不将设计师执行归为本人 |
| 口播／故事 | 真实视频截帧与脚本切入点相邻，身份与原文件入口可见 | 不同讲述任务的处理能力 |
| 参与机制 | 实际规则和关键界面配短解释，避免虚构后台与技术链路 | 用户参与和资源协作 |
| 完整作品 | 清楚命名、类型和数量，补充区有秩序 | 既能精选，也能提供可核对的深度 |

形式共用稳定的对齐、间距和图注规则，不把每段都变为独立卡片，也不依靠大量横向轮播或悬停才暴露主要信息。

## 精华油静态稿

- 桌面：章节侧栏占较小宽度；主区域以标题／简短介绍与大作品并列开篇，角色及整体成绩范围保持可见。正文依次使用原句、日夜对照、长文片段、两条精选成片及成果。
- 手机：顶栏收紧，一条案例章节栏；标题、角色与作品尽早出现，背景说明可在作品之后继续读。线稿和成品保留完整比例，重点不是塞入一屏，而是有清楚的观看顺序。
- 公众号的另外两幅片段、资料海报、朋友圈、另外两条成片与销售重建都在完整作品入口中点名；不能靠只留下“更多”二字声称证据已保留。
- 作品内容不裁掉关键文案。视频预览可在保留原画面的留白区内适配，不将后期截帧认作当年提交的封面设计。
- 当前两条成片副本仅140×192，静态稿使用原尺寸附近的小幅真实截帧与脚本说明并读，不放大当作高清主视觉；截帧时间、来源与尺寸在导出记录中注明。更清晰的原视频需以后由材料补充解决。

## 全站延展

首页保留简短主张与两类主要能力入口，用作品建立第一印象；目录紧凑列出五案。酷狗重点是参与规则和持续内容，用同样的图文、短解释及结果区即可，不强加精华油的海报对照。防晒、面膜、洁面、关于页按[总方案](../../../docs/REFINEMENT-PLAN.md)各自任务处理。

## 参考与检查

沿用此前实际查阅的[Charlotte／Medik8](https://www.thebeautycopywriter.co.uk/liquid-peptides-advanced-mp)、[Lindsey／IMAGE Skincare](https://www.leftyousomenotes.com/lindseys-portfolio/image-skincare)、[Heidi／Hyatt](https://heidiekey.com/case-studies/hyatt-vacation-club)，分别借作品层级、原句配成品、具体判断与克制排版。[视觉设计原则](https://www.nngroup.com/articles/principles-visual-design/)用于校准比例、层级、平衡与对比；不照搬英文巨幅标题、长页留白或自由职业获客模块，不据参考站点推断招聘效果。

UI review逐项看：首屏能否看见作品，视觉重点是否落在有价值信息，正文是否舒服，图组身份是否明确，完整作品是否可发现，桌面和手机是否保持同一信息含义。图中任何删字、弱化关键限定或不合适裁切，都须回到来源检查。
