# UX阅读与交互方案：一条连贯路径，随时能换章节

2026-11-02。针对本轮案例长、往返不便及完整内容难以扫读的问题。本文规定期望行为；静态图只检查安排，真实操作待HTML阶段实现和验证。

## 阅读结构

一案仍有连贯主叙述。先让读者知道任务、本人工作和作品，再通过关键判断与证据建立理解，最后交代成果和贡献。主要论证在正文中闭环，不能要求连续打开多个文件才能知道做了什么。

要点用于扫读；正常正文用于细读；完整作品用于继续核对。这是内容优先级，不要求为三种阅读方式建立三套界面。关键角色、成果范围、后期重建身份始终与相应内容一起清楚呈现。

## 导航

| 场景 | 期望行为 |
| --- | --- |
| 桌面进入案例 | 清楚看到案例名称与全部作品入口；章节侧栏含项目概览、策划与作品、结果与贡献、完整作品 |
| 手机进入案例 | 顶部全站导航正常随页面滚动；只有一条案例章节栏需要常驻，显示当前案／章节和目录入口，不在首屏铺开八项长目录 |
| 打开手机目录 | 一次展开清楚的少量章节，可直接到概览或结果；选择后收起。关闭入口、Esc、焦点返回在实现阶段验证 |
| 读到最后一章 | 通过同一导航直接回概览或其他章节；不用先滚回页面顶部再找目录 |
| 主动跳转章节 | 标题和焦点可见，不被常驻栏遮挡；当前章标识与阅读位置一致 |
| 普通滚动 | 章节状态随阅读更新，接近页尾也不能停留在上一章的错误高亮；不强行吸附滚动或自动切换内容 |

这里的少量顶级章节是同案阅读组织，原有具体作品与小节仍能直接定位；不增加第二套浮动菜单或大量横向标签。

## 完整作品与文件

- 精华油的完整作品区明确列出：资料海报1组、公众号更多片段2幅、朋友圈3幅、其他视频2条、销售沟通后期重建示例；已在正文展示的作品及全文入口继续可查。
- 补充内容展开最多一层。可以同页展开完整文字及作品，保留展开状态与原阅读位置；材料数量多到需要独立查阅时，再按实际阅读目的组织，避免机械分页。
- 海报保持同组关系。图片打开后支持适宽、放大、滚动和清楚关闭；关闭后回到触发入口。不要把整张长图强裁成“好看”的封面而不说明。
- 视频手动播放，用实际截帧作预览；每条有原文件入口，同页切换时暂停其他播放。成片分析与历史原稿身份保持不同。
- PDF、Word、文字版标清类型及完整程度，原有阅读页继续可用。原件入口不等于又生成一份报告。

## 酷狗适配与评审范围

酷狗同样用概览、主要任务、工作范围及完整作品组织导航，具体正文仍是发糖机、音效、晚安电台等任务，不强制改成产品主张和海报模板。旧growth、social、function、wechat、radio等目标继续有明确对应，位于补充区的先展开再定位。

UX review先检查任务路径和状态是否说清、是否会隐藏主要论证或关键身份、是否引入多余步骤。静态图不能验证触控、键盘、播放、历史返回、Safari或真实设备；这些在最后HTML阶段针对实现逐项检查，不提前报为通过。
