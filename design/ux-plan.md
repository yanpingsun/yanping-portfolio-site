# general 通用版 UX r1

日期：2026-11-01。输入：[定位与取舍](../content/brief.md)、[内容 r2](../content/README.md)及现有原作品；参考与证据见[参考比较](references.md)。本方案安排内容如何被找到、理解和查阅，当前不制作代码原型。

## 阅读路径

| 读者要判断什么 | 页面怎样回答 | 可继续做什么 |
| --- | --- | --- |
| 候选人主要做什么，是否值得看 | 首页定位、简短介绍、两个主案例；作品卡显示具体内容问题与个人工作 | 选精华油或酷狗，也可直接看简历 |
| 她实际做了哪些，怎样做 | 案例开头写任务与个人分工；判断之后紧接作品与图注 | 打开原图、完整文章或对应视频 |
| 能否覆盖另一类工作 | 主案例结尾指向互补案例，首页另有三个不同问题的补充案例 | 查看另一个主案例或返回全部作品 |
| 经历与岗位是否吻合，如何联系 | 关于页履历、完整 CV、邮箱；首页和案例结尾也可找到 | 查阅简历或发邮件 |

这是供结构校准的读者任务假设，不声称招聘方都会按固定秒数或固定顺序阅读。允许读者从分享的案例链接直接进入，不要求先看首页。

## 页面与导航

采用姓名入口加“作品、关于、简历 PDF”三项。作品进入简洁项目目录，首页“看代表项目”直接到本页的两个主案例。现有 `#/works`、`#/about` 和五个 `#/project/…` 页面入口在实现时保持兼容，不为改版让旧分享链接失效；本轮不提前确定新增路由或发布结构。

手机优先用可换行的明文导航，常用入口直接可见；320 px 下必要时分成两行，不默认增加折叠菜单。案例标题前有“全部作品”，结尾有互补案例与简历。浏览器返回应回到原列表和阅读位置，分享案例与章节链接应能直接定位；这些行为到实现时检查。

| 页面 | 内容顺序与关键安排 |
| --- | --- |
| 首页 | 姓名与方向、主张、现有简介、作品／简历入口；精华油和酷狗并列，手机依次展示且格式相同；面膜、防晒、洁面用较紧凑条目；简短经历与联系 |
| 作品目录 | 延用五个项目入口，顺序与首页一致；每项保留问题、代表作品与个人工作，不另写一轮重复长摘要；案例不足以支持筛选器与搜索功能 |
| 精华油 | 问题与分工；三个内容判断；公众号三个片段与25页全文；朋友圈三张作品；四条独立视频及脚本说明；有范围的项目结果；标明“后期重建”的销售示例与互补案例 |
| 酷狗 | 业务任务与分工；发糖机实际期次、双入口与奖励规则；按平台展示作品及本人职责；最后补充电台栏目和互补案例。不将跨时期作品合成一场活动 |
| 面膜／防晒／洁面 | 同样具备任务、贡献、判断、作品、结果，但篇幅按问题调整。面膜讲升级与双膜；防晒讲价值和肤感两组问题；洁面围绕一句文案、一张海报与完整文章即可 |
| 关于我 | 简短工作主线与范围；近两段工作附案例；更早经历紧凑列出；教育与语言在后；简历与邮箱保持明显。不增加无依据的能力雷达或技能评分 |

五页[线框](output/pdf/general-ux-r1.pdf)覆盖首页、两类主案例、一类补充案例和关于页。作品目录沿用紧凑条目，不单独制作同质稿；面膜与洁面按上表调整内容，不照搬防晒的每个区块。

## 用真实内容校准

首页保留“讲清产品价值，也让用户愿意参与。”及完整两句话简介，主张、定位与作品不互相重复。移动端若标题换行变多，让作品自然顺延；不为把内容塞入一屏而缩小正文，也不要求首屏同时出现五个项目。

精华油开头明确“内容策划、文案与视频脚本”，随后区分产品方案、视觉和拍摄分工。酷狗把“微博独立负责、其他平台统筹审核、管理两位专员”放在靠前的可读段落中。两页均先让读者知道是谁做了什么，再看团队成果；不以页面封面或徽章代替职责说明。

正文按阅读顺序排列，桌面可在长案例旁提供少量章节入口，手机改为开篇可换行目录，随后正常滚动。精华油目录分为“内容判断、图文作品、四类视频、结果与补充”；酷狗分为“任务与分工、发糖机、平台统筹、补充项目”。手机不增加占据正文的固定底栏。

目前代表文案能够落入这些模块，不需要为了线框删减已有职责、成果范围或作品入口。图注保留在相应作品下方；编辑依据、待核对清单、源文件路径与设计注释不进入网站正文。

## 素材怎样查阅

| 素材 | 页面内 | 打开后与手机处理 |
| --- | --- | --- |
| 图文作品 | 分析后紧接对应片段、图注与“查看原图”；封面可裁切，证据图保留完整内容或标明节选 | 默认适宽，允许放大与查看完整原图；放大区域内可移动，普通页面不横向溢出。返回时保留阅读位置 |
| 完整长图／详情页 | 先给有意义的片段或整体预览，配可读摘要；面膜两张详情页明确分为1／2 | 打开整张原稿后再放大看细节。正文不能只靠一张缩得很小的长图承载核心信息 |
| PDF | 写明“公众号全文”和已核实页数，例如精华油25页、防晒31页、洁面30页；关于页写“简历 PDF · 3页” | 以明确文件链接打开；不在手机正文强制嵌入长 PDF。不承诺浏览器一定下载，遵循系统查看行为 |
| 精华油四条视频 | 四个独立标题、脚本处理说明与可操作播放器：品牌科普、刘晓庆合作、达人答疑、达人使用场景 | 手机单列，手动播放，有基本播放／音量／全屏控制。播放失败仍有直接打开文件入口；不静默自动播放四条视频 |
| 酷狗历史截图 | 以“截图”标识，解释活动入口、规则或内容安排；抖音两项按静态图片展示 | 不叠加虚假播放按钮；截图不作为当前活动仍可参与或跳转链路已经验证的证据 |
| 重建稿 | 标题直接写“销售沟通后期重建示例”，位于补充材料，不抢占原作品位置 | 始终显示非原稿说明，作为补充阅读；网页呈现方式留到实现时选用最简单的正文或文件入口 |

所有原件继续留在原位置，不为版式重新复制素材。首页精华油优先选日夜双瓶图，酷狗优先选发糖机作品；封面只是进入案例的线索，成品视觉不全部归为候选人个人设计。

## 版式与视觉方向

建议使用白底、深色正文和单一链接强调色，主要色彩来自真实作品。统一页面边距、标题层级和图注样式即可，不给每个项目另做品牌网站。中文优先系统无衬线字体；最终字体、色值与图片裁切尚需下一轮视觉校准，本轮 PDF 的灰色框和字体用于结构审阅。

桌面主内容区建议最大1120–1200 CSS px，连续分析文字控制在约680–760 px，作品可适当加宽。正文先以18 px、行高约1.75–1.9试排；手机约17–18 px、左右18–24 px边距，卡片改为单列。以上是待实际浏览器核验的设计起点，不是已经测试通过的数值。

作品标题与问题说明常显，不把必读信息藏在悬停、自动轮播或动效中。不使用整页滚动劫持、鼠标跟随、无关装饰动画。重点入口保留清楚的文字标签；交互状态与文字对比、键盘焦点在视觉稿与实现时共同检查。

## 状态与下一步

本轮已按内容稿逐项核对入口：五个项目、两份主案例的分工、精华油四条视频、全文 PDF、关于页和邮箱都保留。线框 PDF 已渲染逐页检查；这属于静态结构与排版检查，不代替真人试读、手机浏览器、键盘或实际媒体加载测试。

下一轮依据反馈校准真实作品的尺寸、中文篇幅与视觉层级，再进入 HTML 实现。届时检查桌面和320／390 CSS px宽度、文字放大、直接分享与返回、图片放大／关闭、四个视频和各 PDF 的实际行为。后续若补字幕或逐字稿，从原视频转写核对，不把现有脚本分析当成已校验字幕。

CV 是否最新、成果数字与职责措辞继续依据内容核对清单处理。酷狗未确认的引流数字不进入图表或 KPI 区；精华油460万+、防晒120万+、面膜100万+与洁面80万+保留各自范围和团队归因，不统一补造时间段。历史传播原话与作品中的产品主张维持原有语境。
