# general 通用版 UX r2

日期：2026-11-02。依据[完整内容r3](../content/README.md)、[原版UI/UX](../baseline/ui-ux.md)和[参考记录](references.md)校准。完整页面与作品去向见[页面安排](page-structure.md)，静态图见[设计入口](README.md)。本轮交付阅读结构与静态设计，尚未制作网页、播放器或图片交互。

## 本轮决定

| 原版及UX r1的情况 | UX r2采用的安排 | 要解决的具体问题 |
| --- | --- | --- |
| 原版已有暖底、深绿、宋体标题与作品分层；r1提出另换白底 | 继承原版视觉语言，扩大正文与导航的可读尺寸，统一间距与图注 | 让改动围绕阅读，不因重新绘稿而抛开原站已有设计 |
| 原版首页简短、五案目录并列；r3确定两类代表能力 | 首页给精华油、酷狗两个同格式入口，其他三案直接可选；目录仍保留全部五案 | 首页帮助选案，完整案例继续保留深度 |
| r1只按部分内容画五页线框，作品去向未齐 | 八个页面逐段安排；三种代表页面各做桌面与手机完整静态结构图 | 用完整内容检查顺序和媒介安排，明确其他页面尚未逐页绘图 |
| 原版已有主展示与补充展开 | 继承四类护肤品共7组主展示、7组补充；每组线稿、成品、分析与原件入口成组 | 控制默认阅读长度，并保留全部14组对照 |
| 原版有图片对话框、章节与独立视频 | 继承能力，细化手机查阅、焦点、失败入口与返回位置 | 将已有功能和仍待验证的行为分开 |

这些是依据现有材料作出的设计判断，尚无招聘读者试读结果证明新版更优。

## 进入与继续阅读

姓名回首页；顶栏保留“作品、关于、简历PDF”。首页“看代表项目”定位本页代表项目，“作品”进入五案目录，两者名称与行为区分。目录顺序为精华油、酷狗、面膜、防晒、洁面，与首页一致。

桌面顶栏直接显示文字。手机姓名与三项导航可分两行，不用菜单图标隐藏唯一入口；常用按钮与关闭入口预留44×44 CSS px触控区。案例名、问题和个人工作始终可见，图片封面用于辨认作品，不承担读者理解职责的全部任务。

外部直接分享任一案例时，开篇能看见“全部作品”、案例问题、本人工作及整体成果范围。结尾给互补案例、全部作品和简历；共用页脚保留邮箱。关于页保留工作方式、完整履历与联系。

## 长案例的章节与层级

开篇先呈现问题和个人工作，项目整体数字保持清楚范围，不另放大成无上下文的KPI墙。随后按内容r3顺序展开，职责、关键判断、独特作品、成果范围与材料身份常显。编辑说明、源文件路径和设计注释不进入正式网页正文。

桌面长案例使用窄列章节目录与正文相邻，正文和作品各有宽度；短洁面可用开篇章节列表。手机在开篇给可换行的文字目录，正文单列滚动；不使用占据阅读区的固定底栏。若后续采用吸顶目录，必须实际检查缩放时对正文、章节标题和焦点的遮挡。

补充展开的标题写清内容和组数，例如“补充查看：资料信息，1组”。展开后包含完整图组、分析和文件入口，允许直接分享或搜索定位；深链接命中时先展开。图稿身份与职责说明不随补充区一起隐藏。视频、价格问答、直播讲解与各平台独特作品不因篇幅被统统移到一个无名称的“更多”中。

旧分享链接、项目目录、关于与联系入口保持兼容；具体海报组继续定位到对应组。章节切换、浏览器返回和图片关闭分别处理：章节标题可见；浏览器返回恢复来源页面与位置；图片关闭回到原触发处。

## 媒体怎样呈现与打开

| 类型 | 正文内安排 | 打开、失败与返回 |
| --- | --- | --- |
| 线稿与成品 | 标清材料身份与分工；桌面两列完整配对，手机同组先线稿后成品，图注随图；分析紧邻对应组 | 每幅有“查看原图”；适宽显示后可进入原尺寸查阅，保留完整比例；关闭回原组与触发入口 |
| 普通作品与截图 | 说明后紧接作品和图注，核心解释保留文本；截图注明平台与指标范围 | 能查看原图；加载失败仍保留图注及文件入口，不出现空白可点区 |
| 超长图／详情页 | 先显示完整缩略预览及该模块的文字说明；已有合适片段可单独显示；面膜明确上／下段 | 完整图独立查看，允许放大和平移；普通正文不横向溢出；不裁掉作品文字再声称完整展示 |
| 视频 | 精华油4条、防晒4条、面膜3条分别保留标题、说明和原生播放器，桌面两列、手机单列；第三条保留正常卡片宽度 | 手动播放；切换页面或播放另一条时停止之前的声音；原文件入口常可见，失败后仍可另开；不虚构播放次数或高清版本 |
| PDF、Word与文字版 | 标清用途、类型和已核对页数；防晒话术同时给Word原件与文字版 | 跟随浏览器／系统的文件查看行为；若开新标签明确说明，不强制嵌入手机正文，也不承诺一定下载成功 |
| 酷狗、直播静态截图 | 平台内容与文字记录按实际身份显示 | 不叠加假的播放按钮，不能凭图片宣称历史活动仍能参与 |
| 后期重建与事后分析 | 标题和说明持续可见，原稿、文字记录、成片分析、重建分开 | 原件与补充分析保留独立入口，不把脚本分析直接当作经核对字幕 |

视频可用高度受限、完整适配的原生播放区展示竖片，保留原比例及控件。现有材料没有本轮核对的全量字幕；是否补字幕或转写按真实素材安排，不能将本轮静态设计说成已完成媒体可访问性验证。

图片对话框沿用原生方式，提供可见关闭和原图入口；打开时焦点进入内部，Tab／Shift+Tab在对话框中循环，Escape关闭并返回触发入口。手机不要求用户必须识别手势才能关闭或找到原图。长图查看区可二维移动，常规正文保持单向滚动。

## 视觉与尺寸起点

保留原版的编辑式视觉：暖底 `#f6f4ef`，标题深绿 `#26382f`，正文 `#46534a`，赤褐色链接 `#a65336`。宋体类用于主标题与章节，系统无衬线用于正文、导航和图注；不把作品自身的视觉设计归为候选人的个人贡献。

| 项目 | 桌面起点 | 手机起点 |
| --- | --- | --- |
| 外层 | 最大约1200–1280px，边距随窗口收敛 | 390px示意图两侧20px；320px应重新排布 |
| 连续文字 | 约680–760px宽，正文18px、行高约1.75 | 正文17–18px、行高约1.75；不通过缩小字号容纳同一屏 |
| 主标题 | 约44–60px，按语义换行 | 约32–36px，允许自然多行 |
| 章节与图注 | 章节约28–32px，图注14px以上 | 章节约24–26px，图注约14–15px |
| 内容间距 | 使用16／24／32／48／64px层次，作品可宽于分析文字 | 同组图文紧邻，不同章节留清楚间隔，按钮不互相挤压 |
| 表格 | 并列展示个人工作与协作说明 | 逐项排列标签与值，保留对应关系和阅读顺序 |

以上为设计起点，静态图不是CSS测量结果。所选正文、链接及图注色与暖底的计算对比度均超过4.5:1；这只是颜色配对检查，不证明整个网站符合WCAG。原图中的文字另有历史质量与可读性问题，不能由界面配色代替检查。

## 静态图的范围

首页、精华油与酷狗分别绘桌面和390px手机两种完整结构。直接取内容r3“网页正文”的全部块，图像保留原比例，视频以有明确标识的静态区域表达。补充材料在审阅图中全部展开；图上明确标为结构稿及不可交互。

长手机图为查阅与图片格式限制按章节切成连续部分，不删除中间正文；完整SVG和分片范围可核对。SVG引用仓库原件，位图是设计导出，不替换源图片。封面可节选并标明，作为证据的图稿保持完整。面膜、防晒、洁面、目录、关于页已逐段安排，尚未分别制作完整视觉图。

## 本轮核对与实现时验证

本轮检查内容块与作品的完整映射、图组主次、各媒体身份、静态图文字边界和文件引用。没有修改内容r3、CV、素材或网站代码，没有重做报告PDF。

HTML阶段实际检查：桌面及320／390px宽度、文字放大与重排、键盘焦点及遮挡、进入和关闭图片、全部11条视频、文件入口、深链接自动展开、浏览器返回及手机长图查阅。故障时应显示原图／文件或全部作品入口。正式发布前的CV与待核对数据仍按内容清单处理，不将未确认数字做成图表或大标题。

完成这些实际验证并提供独立预览后，由用户查看并确认具体版本再切换正式入口。UX r1与原站节点继续保留，本轮并未部署。
