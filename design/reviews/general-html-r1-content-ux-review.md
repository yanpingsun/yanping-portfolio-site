# general HTML r1：内容与阅读体验复核

日期：2026-11-02。针对用户试读提出的案例过长、导航往返不便、文字偏杂及展示偏干的问题。本文仅为研究与设计建议，尚未采纳或实现；不修改内容r3、UX r2、网页或正式入口。

## 判断与依据

当前通用版面向产品内容策划、新媒体运营相关岗位。需要让快速浏览者看懂候选人的定位与贡献，也让业务负责人有作品可深入查阅。现有原件及完整内容继续是基础，不能用机械删减或大量折叠代替编辑。

本轮重读七份页面稿、定位与证据说明，对照原版首页和精华油案例，实际查看原版与预览的精华油开篇、海报章节、手机宽度布局；查阅三个同类作者的案例并在桌面浏览器观察首屏及部分正文。以下审美和取舍是本项目的编辑判断，不是招聘读者测试结论。

原版的大作品图、短主张和层级更有展示感；r3在个人职责、材料身份和数字范围上更清楚。下一版应保留这些已有优点，并解决新增说明与展示方式的问题。

| 观察 | 阅读影响 | 建议 |
| --- | --- | --- |
| 精华油开篇、任务、判断与结尾反复解释“选择主线，再延展到渠道” | 增加篇幅，新增判断却不多 | 背景和职责集中交代；后续文字只补充作品本身看不出的选择、理由与限制 |
| 多组图前后重复说明标题、分组、图文对应及设计师制作 | 容易读成图片结构说明书 | 可直接看出的结构压成短图注；正文保留为什么这样写、舍弃什么、解决哪一个问题 |
| 原作中的“表补油，里补精华”等文案埋在说明段落中 | 难记住候选人的实际表达 | 将少量代表文案作为视觉重点，与相关成品和简短解释相邻；仍注明历史作品身份 |
| 五案普遍按海报、公众号、朋友圈、视频等渠道铺开 | 容易感觉案例相似，独特能力出现较晚 | 每案围绕最有辨识度的问题选择主叙述，其余交付清楚保留去向 |
| 通用事实说明、成果限定与材料说明分散重复 | 语气偏审稿记录，打断阅读 | 共通职责和作品身份集中说明；数字的范围就近保留，后期重建等关键身份仍贴对应材料标明 |
| 精华油新版首屏图明显小于原版，说明段落占主导 | 第一印象更接近文档阅读 | 恢复代表作品的展示面积，缩短开篇，把问题、职责与成果做成简洁可读的信息 |

手机宽度检查使用与已发布预览四个运行文件逐字节一致的现有QA副本：390px外框、375px正文视口、880px高。精华油目录约占179px，代表作品约从页面999px处开始，首屏未出现作品；默认页面约18205px高。尺寸只描述此检查条件，不能直接当作真实手机阅读时长。桌面侧栏虽常驻，缺少明确的案例概览入口；部分章节高亮与当前位置也需复核。

首页原版“把产品价值，写成选择理由”更集中，值得保留为候选；新媒体运营能力可以由副标题、经历和酷狗入口补足，不必让一个主标题承担全部履历。关于页的开篇、方法和履历也有重复，可压缩介绍，保留清楚的任职信息与案例去向。

| [Charlotte Smith／Medik8](https://www.thebeautycopywriter.co.uk/liquid-peptides-advanced-mp) | 护肤品沟通任务与本项目接近；把产品问题、核心传播主张与跨渠道成品分出层级，用作品形成视觉节奏 | 站点本身也很长；不把长页、巨大标题、整套策略示意图或自由职业获客模块视为标准答案 |

| [Heidi Ekey／Hyatt Vacation Club](https://heidiekey.com/case-studies/hyatt-vacation-club) | 排版克制，具体讲述用词规则与执行取舍，说明文字因细节而有辨识度；作品目录还区分深度案例和其他样本 | 不照搬巨幅英文标题、较长首屏或所有文字密度，也不据其个人叙述验证商业效果 |

[NN/g的在线阅读研究](https://www.nngroup.com/articles/how-people-read-online/)支持便于扫读的结构；[其作品集建议](https://www.nngroup.com/articles/ux-design-portfolios/)强调问题、本人角色、判断与结果，并提醒避免炫技模板。后者针对UX招聘，只借通用呈现原则，不等同于中国内容运营岗位的直接招聘证据。研究不支持为本项目设定统一的“HR只看几秒”或字数削减比例。

## 建议方向：一篇有主次的案例，轻量导航

优先保留一案一条连贯阅读路径，先把内容编辑好，再校准是否还需要拆页。默认阅读可围绕“项目概览—策划与代表作品—结果与贡献”组织；完整交付有明确入口，不要求读者先读完全部材料才形成判断。

- 开篇保留简短问题、个人职责、代表作品及已有整体成果范围。成果已在现稿开篇出现，不将“前置成果”算作新增改进。
- 每个主模块以一条具体判断、对应作品和少量说明组成。真实文案、对照图、脚本片段各用合适形式呈现；无需把所有段落都装进卡片。
- 完整海报、全部视频、长文、历史话术与其他原件继续可查。默认展示的取舍依据独特证据，而非统一按数量或页面长度删减。关键证据不藏进难找入口，补充区域标清作品类型和数量。
- 桌面使用克制的章节侧栏，加入明确的案例概览；手机只保留一条紧凑的当前章节／目录入口。避免多条吸顶栏、横向八项标签、多层展开与独立悬浮控件同时出现。
- 视觉继续使用中性暖底、深绿与有限强调色；作品自身的色彩提供变化。统一标题、正文和图注关系，说明行宽适合阅读，作品留足空间。无需新增装饰图或动效来制造丰富感。
- 如编辑后仍需拆分，优先按有独立阅读目的的内容拆页；不按屏幕长度切成第1、2、3页，也不默认将八章变成八个页面。

## 五案应该各有重点

| 案例 | 主叙述优先呈现 | 其余材料的处理 |
| --- | --- | --- |
| 精华油 | 一句共同主张怎样区分日夜，并进入不同讲述方式 | 全部图文、四条视频、原文与重建话术保留，减少重复的结构解释 |
| 酷狗 | 发糖机的参与入口、玩法及资源协作，再用平台与栏目补足持续运营 | 平台截图和各自指标保留，不把所有平台做成同等篇幅的逐项履历，也不混合数字 |
| 防晒 | 价格顾虑与使用顾虑分别怎样回应；历史问答和体验型脚本是重要证据 | 海报、全文、详情和四条视频继续可查，强调文案差异而非重复图文层级术语 |
| 面膜 | 升级沟通、人物故事转场及直播讲解的独特处理 | 海报与长详情保留，直播文字记录的身份和本人参与边界继续清楚 |
| 洁面 | “油皮洗得净，干皮不紧绷”的短文案与成品对照 | 保持叙述集中，三组海报和长文均保留入口，不套成长篇主案例模板 |

一个内容组织示例：将精华油已有“表补油，里补精华”作为原作文案重点，紧邻日夜作品，短说它如何概括共同特点、如何用两组场景解释差异；职责集中标明文案／内容结构与视觉制作分工。它替代的是反复泛述“组织信息”的段落，不替代完整原作，也不新增历史事实。此例仍是编辑建议，不是已经改好的网页正文。

## 下一步与边界

建议先用精华油做一次小范围内容取舍与版式对照，逐项写清保留、合并和移至补充阅读的理由；对照原版、现预览与提议稿看同一批证据。随后用酷狗检查另一类内容任务是否同样成立。方向确定后再修订正式内容稿、UX安排，最后实现HTML，不直接全站重做。

本轮没有改写CV、补造结果、重新认定历史材料，未测试真实手机触控、Safari、所有参考站的完整交互或招聘读者表现。技术可用性检查与内容有效性、审美判断分别记录。本建议不构成投递确认或正式发布授权。
