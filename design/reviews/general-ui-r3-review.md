# UI r3：视觉自审与调整

2026-11-02。对象为精华油1280px桌面、390px手机及手机菜单静态稿；依据[UI方案](../proposals/general-ux-r3/ui-plan.md)。此处只评视觉表达，不代替[内容review](../../content/reviews/general-r4-pilot-review.md)或[UX review](general-ux-r3-review.md)。

## 已发现并调整

| 首稿发现 | 调整 | 复核 |
| --- | --- | --- |
| 桌面主标题最后一字单独落行 | 保留原文，按句中逗号安排两行；部分小标题使用更均衡的换行 | 实看开篇与手机海报段，未用删字解决 |
| 手机目录箭头在当前字体下显示异常 | 使用简单矢量折线表示箭头 | 静态图中可辨认，不新增一套控件 |
| 视频副本只有140×192，放大不适合做主视觉 | 以小幅实际截帧与脚本说明并读，明确“压缩查阅版” | 核对实际帧及尺寸，未生成假高清或假封面 |
| 刘晓庆初选帧未清楚呈现人物 | 对照原片25、45、65、95秒实际帧，选25秒 | 截帧来源与时间记录在manifest，未改变原视频 |
| 细长标题在窄屏出现单字坠行 | 平衡标题换行，正文内容保持原样 | 复核手机海报与视频段 |

## 分项结果

- 开篇：大幅真实作品与简短身份／主张并列；手机静态稿约373px处出现作品，在一屏内有明确视觉内容。这里只描述静态图，不与旧网页按高度计算招聘效果。
- 层级：原作文案有明确字号与位置；主要正文保持正常可读，角色和整体成果范围用深色呈现，未藏进淡小字。
- 作品：日间、夜间各自保留线稿与成品配对、身份标签和原图入口；图片保持比例，原作关键内容未裁切。
- 节奏：原句、图文对照、长文片段和小幅成片证据有变化，共用同一组字体、对齐和间距。没有逐段套卡片或新增装饰图。
- 完整性：主叙述37个来源块均在默认稿中呈现；完整作品以五个具名入口表示，完整内容仍在文稿。来源哈希、素材路径、SVG结构及横向文字边界已检查，记录见[manifest](../proposals/general-ux-r3/layouts/manifest.json)。

实际查看了开篇、海报对照、视频、手机目录等局部，并核对整页导出结构。静态输出为桌面5727px、手机8101px高，不以页面更短作为通过依据；源稿及原件没有被设计工具改写。

## 结论与待确认

首轮视觉调整已完成，可用于与原版／现预览同层讨论。仍是试点提案，不宣称审美已经得到候选人或招聘读者认可。更清晰的成片待材料补充；酷狗整页视觉及其他页面未绘制，不能据单案宣布全站UI完成。静态图不验证真实字体回退、320px重排、浏览器缩放或真机触控，这些随HTML阶段检查。
