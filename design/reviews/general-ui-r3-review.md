# UI r3：整批视觉自审与调整

2026-11-02。对象为八页的1280px桌面／390px手机静态稿，以及目录、结果位置、补充展开三种状态，共19张查看图。依据[UI方案](../proposals/general-ux-r3/ui-plan.md)，只评视觉；[内容review](../../content/reviews/general-r4-review.md)和[UX review](general-ux-r3-review.md)分别维护。本记录是同一agent的分项自审，不是外部设计评审。

## 已发现并调整

| 发现 | 调整 | 实际核对 |
| --- | --- | --- |
| 精华油桌面主标题末字独落、部分窄屏小标题坠行 | 保留原字，按语义和可用宽度平衡换行 | 首轮开篇、手机海报及视频段 |
| 手机箭头字形异常 | 改用简单矢量折线 | 菜单及案例栏静态状态 |
| 精华油视频副本仅140×192 | 小幅真实截帧配脚本说明，不作为高清大图 | 对照原片实际帧；刘晓庆由初选帧调整到25秒 |
| 全站延展中将“历史主张”后的解释也整段放大 | 只放大原句，身份标签与正常正文分开排；解释不删字 | 防晒、面膜、洁面实际导出 |
| 酷狗标题把“具体”拆到两行 | 按“让粉丝兴趣／有具体的参与入口”安排完整语义 | 桌面与手机开篇 |
| 防晒长主张窄屏拆开“精华” | 来源标签独立，原句按原有逗号换行 | 手机主张段，原词、标点与限定仍保留 |
| 首页导语和紧接案例简介重复，让作品出现偏晚 | 问题返回内容稿，收短导语后重新导出 | 内容review记录同一修改，不在图里另改稿 |
| 补充展开图仍显示“项目概览” | 案例栏改为“完整作品”，增加清楚的收起入口 | 面膜后期重建展开状态 |

## 逐页视觉判断

| 页面 | 采用的重点 | 观察与限制 |
| --- | --- | --- |
| 首页 | 大短句、两组作品与简介相邻、三案文字入口 | 原件有足够面积；手机按顺序读，不靠悬停；导语仍有正常阅读长度 |
| 目录 | 五条作品行，职责与摘要同行 | 缩略图只用于识别，不能代替原作细看；没有新增筛选控件 |
| 精华油 | 原句、日夜配对、长文片段、两种讲述 | 不把每段放进卡片；低清视频保持小幅 |
| 酷狗 | 发布微博与规则并读、功能截图、电台作品 | 静态证据有明确身份；不虚构界面、技术路径或整合总成绩 |
| 防晒 | 历史价格问答、价值与肤感两组对照、人物视频 | 使用原稿引文区域，不伪装实际聊天；条件、职责与团队范围可读 |
| 面膜 | 升级图、双膜配对、故事、主播文字记录 | 直播截图是证据预览，全文需查原图；制作和原创范围未因排版扩大 |
| 洁面 | 短句与一组主对照、长文入口 | 没有为拉齐主案例长度增加无关模块；另外两组仍具名可查 |
| 关于我 | 工作方式、公司／时间／职责、教育与联系 | 没有案例目录或装饰性评分条，履历采用稳定层级 |

角色、整体成果范围及重建身份没有藏入低对比小字。主要正文桌面18px／手机17px，角色等采用16px；来源／图注14px左右。海报保留比例和关键文案，不裁切成无法核对的局部。新增四张视频帧来自提供文件20秒处，精华油两帧分别8／25秒，来源、尺寸与时间可回查manifest。

## 核对范围

实际查看全部八类页面的开篇／整页缩览，并放大检查手机原稿问答、历史主张、故事视频、海报、完整作品区、目录与结果状态；依据观察进行了上表调整。程序另外核对主叙述块没有遗漏、补充组有来源范围、16张整页的文稿哈希一致、SVG结构及图片路径存在、导出文字无横向越界。

这些核对不覆盖真实浏览器字体回退、320px重排、200%缩放或真机触控；静态SVG／位图也不能证明所有交互已经实现。图像尺寸和主叙述长短只用于检查，不据此宣布招聘效果提高。既有原件、内容r3、UX r2与HTML r1未被替换。

## 当前结论

本批静态UI及已发现问题的调整完成，可以逐页与原版、现有预览及内容稿同层比较。候选人的审美／语气认同与招聘读者反馈仍待实际试读。最后实现HTML时再验证真实重排与交互，不把静态自审当作发布验收。
